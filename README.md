# 🔢 Logic Box  
A mini number-logic tool built using **HTML, CSS and JavaScript**.  
It lets users check various numeric properties and generate sequences.

## ⭐ Features  
- Prime Number Check  
- Armstrong Number Check  
- Perfect Number Checker  
- Palindrome Number  
- Factorial Calculation  
- List of Prime Numbers  
- Factors of a Number  
- Fibonacci Series  
- Triangular Numbers  

## 🎨 Tech Stack  
- HTML  
- CSS  
- JavaScript (DOM + Basic Logic)

## 🚀 How to Use  
1. Enter a positive number in the input box  
2. Click any button to check or display results  
3. Output will appear instantly in the result area
